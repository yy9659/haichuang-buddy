## 应用资源

现有界面资源位于 `public/assets/`：

- `haichuang-logo.png`、`haichuang-wordmark.png`：品牌标识与文字。
- `buddy-mascot.png`：侧栏助手形象。
- `dashboard-ocean.png`：工作台海洋背景。
- `ocean-bg.mp4`：登录与注册页背景视频。

部署自己的品牌时，可替换这些文件并更新对应页面的文案。商品照片由使用者上传，不随业务数据库公开发布。

## 许可与替换

项目原创代码和文档采用根目录的 [MIT 许可证](../LICENSE)。第三方依赖、商品照片与其他第三方资源遵循各自许可；MIT 不授予第三方素材或品牌商标的额外权利。发布自己的商品海报时，应使用自己有权使用的照片与品牌素材。

后续更新截图建议使用清晰的横屏 PNG，保持同一商品案例，隐藏真实邮箱、密钥、Cookie 和客户信息，并保留模拟或演示标记。将新文件放入本目录并同步更新 README 的图片说明。
